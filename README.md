# LogSentinel AI 🛡️

An intelligent log monitoring and anomaly detection platform 
that uses ML to detect threats, suspicious patterns, and 
system vulnerabilities in real-time.

## Features
- 📁 Upload server logs (Nginx, Apache, custom APIs)
- 🤖 ML-based anomaly detection (Isolation Forest)
- ⚡ Real-time WebSocket alerts
- 🧠 AI-powered root cause analysis
- 📊 Interactive threat dashboard
- 🔔 Severity-based alert system (Low/Medium/High/Critical)

## Tech Stack
- Frontend: React.js + Tailwind CSS + Recharts
- Backend: Node.js + Express.js
- ML Service: FastAPI + Python + Scikit-learn
- Database: MongoDB
- Real-time: Socket.io
- AI: Anthropic Claude API
